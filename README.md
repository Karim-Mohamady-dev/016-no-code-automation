# Flowlink — 016-no-code-automation

صفحة هبوط ثنائية اللغة (العربية RTL والإنجليزية LTR) لمشروع 016-no-code-automation ضمن استوديو 100 مشروع ويب.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

## البنية

- `src/App.tsx` — أقسام الصفحة: تنقل، بطل، مزايا، كيف يعمل، قسم الشعار، عرض تفاعلي، آراء، أسعار، أسئلة شائعة، نموذج تسجيل، تذييل.
- `src/components/Demo.tsx` — العرض التفاعلي الخاص بالمشروع.
- `locales/en/common.json` و `locales/ar/common.json` — كل النصوص، واللغة المحفوظة في localStorage.
- `src/index.css` — نظام التصميم (خط Poppins، ألوان مسطحة، حركات cubic-bezier(0.22,1,0.36,1)).

## ملاحظات

- الأسعار عناصر نائبة بصيغة {{...}} حتى يتم تحديد الأسعار النهائية.
- قصص العملاء وأرقام العرض موسومة كعينة تجريبية وليست حقائق حقيقية.
- اتبعنا قواعد نظام التصميم: خط واحد، لا مائل، لا تدرجات في الخلفيات، تدرج نص العنوان فقط.
